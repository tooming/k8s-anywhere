# docs/dependency-tree.md — fix stale pre-ApplicationSet NetworkPolicy references

ROADMAP rule #9's coverage/hardening fallback lane names "a doc page that's drifted
from the code it describes" as always-real, always-available work — continuing the
sweep from the `vault-unsealer` fix (this same day). Cross-checked every
`` `gitops/platform/<name>.yaml` `` file reference in `docs/dependency-tree.md`
against the actual filesystem and found 8 stale references, all sharing the same
root cause.

`gitops/platform/networkpolicy-appset.yaml`'s own header comment says it "Replaces
the 9 standalone `*-networkpolicy` Application manifests with a single List-generator
ApplicationSet" — but 8 prose bullets in `docs/dependency-tree.md` (capstone,
observability, vault, storage, argocd, moto, ack-system, lab-gateway) were never
updated after that migration: each still claimed "Deployed by the auto-synced
`<name>-networkpolicy` ArgoCD Application (`gitops/platform/<name>-networkpolicy.yaml`,
wave 4)" — a file that no longer exists (these Applications are now generated by the
`networkpolicy` ApplicationSet's list-generator, sourcing `gitops/<component>/networkpolicy/`
directly). This is exactly the kind of claim ADR-0004 exists to prevent — asserting a
concrete resource path as real state when it isn't. The doc's own `tidb`,
`tidb-admin`, `lab-demo`, and `istio-system` bullets already used the correct,
already-fixed wording ("via `networkpolicy-appset.yaml`") — this was a partial
migration that was never finished for the other 8 entries.

The 9th "standalone" case, `envoy-gateway-system-networkpolicy`, is untouched: that
one genuinely is a standalone auto-synced Application
(`gitops/platform/envoy-gateway-system-networkpolicy.yaml` exists on disk), so its
existing description was already accurate.

## Changes

- `docs/dependency-tree.md`: for the 8 affected bullets, replaced "Deployed by the
  auto-synced `<name>-networkpolicy` ArgoCD Application
  (`gitops/platform/<name>-networkpolicy.yaml`, wave 4)." with "Deployed by the
  auto-synced `<name>-networkpolicy` Application (via `networkpolicy-appset.yaml`,
  wave 4)." — matching the wording already used correctly elsewhere in the same
  document.

`make ci` passes (bats/lint locally; full suite in GitHub Actions). Docs-only change.
