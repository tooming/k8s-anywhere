## What was verified at pickup time

Re-confirmed directly (fresh clone, not the planner note's cached read) that
`grafana-12.10.2` → `grafana-12.10.3` in `grafana-community/helm-charts`
touches only `charts/grafana/Chart.yaml` — `values.yaml` and
`templates/_pod.tpl` are byte-identical between the two tags, so the
long-running security due-diligence comment chain in
`observability-grafana.yaml` (securityContext/containerSecurityContext/
initChownData defaults + the unconditional "search" emptyDir, re-verified at
every chart bump since `12.7.2`) holds unchanged at `12.10.3` — extended that
comment chain in place rather than replacing it, per the existing convention.

## Rollback path

Revert `gitops/platform/observability-grafana.yaml`'s `targetRevision` to
`12.10.2` and push. ArgoCD self-heals within its sync interval — Grafana's
database (dashboards state, sessions) lives on a PVC untouched by a
chart-version revert, so no data loss.
