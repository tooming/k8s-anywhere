## ADR-0004 caveat

This remote, clusterless session cannot verify kube-state-metrics reconciles
cleanly and the stack-health/KSM dashboards keep populating post-bump on a
live cluster.

## Rollback path

Revert `targetRevision`; ArgoCD re-syncs the prior chart version on next
reconciliation. kube-state-metrics is stateless, so a rollback recovers
immediately with no data loss.
